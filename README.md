# YouTube Money Academy — Telegram Bot STANDARD

Демо-бот для портфолио: наставник по YouTube-монетизации.

## Что внутри
- главное меню с медиа-баннером;
- раздел «О наставнике»;
- 3 курса;
- прайс;
- бесплатный PDF-урок;
- раздел «Чему научитесь»;
- контакты;
- форма заявки;
- уведомление админу;
- GitHub Actions для демо-запуска.

## GitHub Secrets
Добавить в Settings → Secrets and variables → Actions:

- BOT_TOKEN
- ADMIN_ID

## Запуск через GitHub Actions
Actions → Run YouTube Standard Bot → Run workflow.

Бот будет работать около 28 минут, затем GitHub Actions остановит процесс. Для демо можно запускать вручную перед показом.
